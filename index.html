Google Apps Script & Cloud Sync Setup

Hubungkan aplikasi ini dengan Google Spreadsheet Anda agar dapat digunakan bersamaan dari banyak perangkat.

Tempelkan Web App URL hasil Deploy Google Apps Script di sini.

Panduan Menghubungkan Banyak Perangkat

  1. Buat Google Spreadsheet baru di Google Drive Anda.
  2. Buka menu Extensions (Ekstensi) > Apps Script.
  3. Klik tombol di bawah ini untuk melihat dan menyalin kode Code.gs.
  4. Tempelkan di Apps Script, lalu klik Deploy > New Deployment.
  5. Pilih jenis Web App, set Execute as: Me, dan Who has access: Anyone.
  6. Salin Web App URL dan simpan di HP/Laptop mana pun yang Anda gunakan. Data akan otomatis terhubung selamanya!
